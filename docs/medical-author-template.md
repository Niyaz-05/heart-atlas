# Шаблон медицинского автора

Не нужны MDX, YAML, Git или собственная анимация. Передайте текст через [GitHub Issues](https://github.com/w3lld1/heart-atlas/issues/new), указав статью. Всё в публичном репозитории/issue/ветке публично: никаких данных пациентов, документов о квалификации, личных заключений или изображений без разрешения.

1. Аудитория: пациент / студент; что читатель уже знает.
2. Два–три учебных результата, сформулированных обычным языком.
3. Основное объяснение и краткий вывод.
4. Частое заблуждение и границы применимости объяснения.
5. Цель интерактива: структура / сравнение / последовательность / термин.
6. Каждый шаг/состояние: заголовок, текст, источник и ограничение модели. Для клапанов доступны только существующие diastole/systole; новые фазы требуют отдельной разработки и медицинской проверки.
7. Для учебного заключения: термин, вымышленная формулировка, простое пояснение, уточнение студенту, ограничения, источник, связанная статья. Не реальные документы, не классификация личных показателей.
8. Вопросы для понимания с вариантами, правильным ответом, пояснением и источниками.
9. Полные источники: URL/DOI/ISBN, конкретный поддерживаемый тезис/раздел. Доступность URL не подтверждает тезис.
10. Предложенный ответственный за обновление и конкретная дата следующей проверки (согласуются отдельно).

Редактор переносит согласованный текст в draft и проверяет точный результат. Автор не рецензирует себя. Пока врачей нет, новые медицинские тексты не публикуются. Текущие статьи остаются опубликованными и честно непроверенными; этот технический пилот не изменяет их медицинский текст.
