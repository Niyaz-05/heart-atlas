# Этап 3. Статьи о болезнях

Статус: согласована · 11.10.2026
План MVP: этап 3 «Болезни». Источники: [2026-10-11-stage-3-sources.md](2026-10-11-stage-3-sources.md).

## Цель

На сайте есть шесть статей о болезнях на русском и английском. Каждую статью можно читать на двух уровнях, «пациент» и «студент», внизу стоит список источников, а пока врач её не проверил, сверху висит плашка «Врачом не проверено».

## Что входит

1. Страница статьи `/<locale>/<type>/<slug>/` и список статей типа `/<locale>/<type>/`.
2. Компоненты `<Patient>` и `<Student>` для MDX и переключатель уровня.
3. Блок источников.
4. Шесть статей на русском, затем их перевод на английский.

## Что не входит

Пресеты болезней для «часов сердца» и режим «норма / болезнь»: им нужен пакет `heart-clock` из этапа 2, которого ещё нет. Поля `structures`, `preset` и `related` из плана MVP добавим в схему вместе с этапами 1 и 2, а пока схема их не принимает. Граф связей и статьи по анатомии тоже идут позже.

## Ключевые детали

### Маршруты и fallback

- Коллекция `articles` даёт id вида `ru/disease/atrial-fibrillation`. Slug одинаковый во всех языках и пишется по-английски, чтобы переключатель языка вёл на ту же статью.
- `getStaticPaths` строит страницу для каждой локали из реестра и каждой пары `<type>/<slug>`, которая есть хотя бы в одном языке. Если статьи нет на языке страницы, берётся первый язык из цепочки `fallback`, у которого она есть. Страница тогда показывает пометку «Перевод ещё не готов» со ссылкой на раздел о переводе в `CONTRIBUTING.md`, а у текста статьи стоит `lang` языка оригинала.
- Если статьи нет ни в одном языке цепочки, страница не создаётся.
- Список `/<locale>/<type>/` показывает статьи этого типа с тем же fallback. Главная ссылается на список болезней.

### Уровни «пациент» и «студент»

- В MDX автор пишет `<Patient>…</Patient>` и `<Student>…</Student>` без импортов: страница передаёт компоненты через `<Content components={...} />`.
- Текст вне этих тегов виден на обоих уровнях. Так общие факты (определение, когда вызывать скорую) пишутся один раз.
- Переключатель стоит над статьёй. Выбор хранится в `localStorage` и применяется атрибутом `data-level` на `<html>` до первой отрисовки, поэтому текст не мигает. По умолчанию уровень «пациент».
- Без JavaScript видны оба уровня с подписями «Для пациентов» и «Для студентов», а переключатель скрыт. Так текст доступен всем.
- Переключатель сделан из двух кнопок с `aria-pressed`. React-остров для этого не нужен, хватает маленького встроенного скрипта.

### Блок источников

- Нумерованный список внизу статьи: название, организация из `trusted-sources.yaml` (для `guideline` и `reference`), год, ссылка на DOI (`https://doi.org/<doi>`), иначе `url`, для учебника ISBN.
- Под списком строка «Источники сверены <дата>» с датой в формате локали через `Intl.DateTimeFormat`.
- Плашка «Врачом не проверено» стоит над статьёй, пока `review` равно `null`.

### Как пишутся статьи

Правила из `CLAUDE.md` и спеки этапа 0 действуют полностью. Дополнительно:

- Каждый медицинский факт должен быть в одном из источников статьи. Цифры (частота, пороги давления, сроки) берутся только из рекомендаций или StatPearls. Если факт не удалось сверить, его нет в статье.
- Источники берутся из таблиц спеки источников. Устаревшие документы из её списка не цитируются.
- Нет доз, схем лечения и советов «что принять». Лечение описывается на уровне подходов («препараты, которые снижают риск инсульта», «операция по замене клапана»), со ссылкой на врача.
- В каждой статье есть раздел «Когда срочно вызывать скорую», если болезнь бывает неотложной.
- Структура статьи: что это, почему возникает, симптомы, как ставят диагноз, как лечат (подходы), когда срочно к врачу. Уровень «студент» добавляет патофизиологию, классификацию и диагностические критерии из рекомендаций.
- Русская версия пишется первой. Английская версия переводит её смысл, источники те же.

## Риски

- Без рецензентов ошибка в статье может дойти до читателя. Защиты три: только проверенные источники, плашка с кнопкой «Сообщить об ошибке» и правило «нет источника, нет факта».
- Рекомендации Минздрава по нескольким болезням должны обновиться в 2026 году. Перед мерджем каждой статьи автор проверяет рубрикатор.
