# Heart Atlas

Открытое интерактивное веб-приложение о сердце и сердечных болезнях: 3D-анатомия, живой сердечный цикл с ЭКГ и статьи о болезнях с проверенными источниками. Работает в браузере, бесплатно, на любом языке.

An open-source interactive web app about the heart and heart disease: 3D anatomy, a live cardiac cycle with ECG, and articles on heart conditions backed by verified sources.

> Проект на этапе 0. План MVP и спеки этапов лежат в `docs/plans/`.
>
> Это образовательный ресурс. Он не заменяет консультацию врача.
